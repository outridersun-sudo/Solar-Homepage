# 인버터 선정 제외·미선정 상세 표시

계산기 페이지의 가장 하단에 빨간색(`#c00000`) 12px 설명을 표시합니다. 현재 선택한 A/B/C 구성안에 포함되지 않은 등록 인버터를 대상으로 합니다.

## 구분

- **AC 전압군 불일치**: 선택한 AC 전압과 제품 AC 전압을 직접 비교합니다. 380V·800V 제품을 혼합하지 않는 기존 선정 규칙에 따른 후보 제외이며 전류 초과라고 표시하지 않습니다.
- **전기 조건 미충족**: 직렬 수 범위 불일치와 병렬 수별 전류 초과를 계산값·제품 한계값으로 보여줍니다.
- **전기 조건 충족, 조합 미선정**: 전압·전류는 통과했지만 현재 선택한 조합에 들어가지 않은 경우입니다. 선택안의 선정 기준, AC/DC 목표·편차·모듈 전량 배분 조건 및 다른 A/B/C안의 포함 여부를 함께 표시합니다. 미선정을 전류 초과나 제조사 접속 불가로 단정하지 않습니다. 제품 1대의 AC가 전체 허용 AC 상한을 초과하거나 전체 모듈 수가 최소 스트링 장수보다 적은 경우에는 그 수치도 직접 비교합니다.

모든 구성안이 없더라도 현재 계산에 따른 후보별 진단을 표시합니다. 입력이 바뀌거나 계산이 실패하면 이전 상세 내용을 숨깁니다.

## 비교값

각 전압군 내 제품에 대해 다음을 표시합니다.

1. 모듈 양면·온도 보정을 반영한 스트링 Imp 계산식
2. Isc 및 추가 단락전류 보정계수를 반영한 스트링 검토 Isc 계산식
3. 1~제품 최대 병렬 수별 스트링 Imp 한계, MPPT Imp 합계 한계, MPPT Isc 합계 한계와 판정
4. 110·60kW의 단일 스트링 전류 예외 정격(19.2A)
5. 고온 Vmp·기동/MPPT 하한으로 계산한 최소 직렬 수
6. 저온 Voc 및 DC 상한·저온 Vmp 및 MPPT 상한으로 계산한 최대 직렬 수

예: 통웨이 TWMNF-66HD750, 자료 재현 모드, 최저 -20℃·최고 40℃·후면 13.5% 조건에서 스트링 Imp는 19.71 × 1.0207 = 20.117997A입니다. 150kW의 스트링 한도 18A를 초과해 허용되는 병렬 수가 없습니다. 표시는 20.118 > 18A입니다.

표시값은 반올림하며 판정에는 기존 엔진의 반올림 전 수치와 허용 오차를 그대로 사용합니다. 일부 병렬 수만 실패하고 다른 병렬 수가 허용되면 제품 전체를 전류 초과로 제외하지 않습니다. 퓨즈 참고 선정 결과를 새로운 후보 제외 규칙으로 추가하지 않습니다.

## 소스 및 적용

- `server/calculator-engine.js`: 기존 선정에 쓰는 전류 비교 결과와 직렬 수 범위를 진단 데이터로 전달합니다. 기존 구성안 선정 조건은 유지합니다.
- `public/js/calculator.js`: 선택안과 진단 데이터에 맞는 설명을 렌더링합니다.
- `public/calculator.html`: 페이지 최하단 영역과 빨간색 12px 스타일을 추가합니다.

기존 프로젝트 폴더에 수정 ZIP의 경로대로 덮어쓰고 Node.js 서버를 재시작하세요. 이번 버전은 삭제할 파일이 없습니다. `.git`, `.env`, `uploads` 및 카탈로그는 그대로 보존합니다. Windows PowerShell에서는 기존 방식대로 `npm.cmd start`를 사용할 수 있습니다.

검증:

```sh
node --test --test-isolation=none test/inverter-exclusions.test.js
node test/inverter-exclusions-ui.cjs
npm test
node test/calculator-ui.cjs
```

브라우저 테스트는 Playwright·Chromium이 있는 개발 환경에서 기존 Origin 허용 포트인 3000을 사용합니다. 테스트 전에 해당 포트를 비워두세요.
