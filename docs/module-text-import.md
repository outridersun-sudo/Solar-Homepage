# 28개 열 텍스트 등록

등록 화면의 기본 흐름은 GPT에서 정리한 TSV를 한 번에 붙여넣고, 원본과 대조한 뒤 선택한 모델을 등록하는 방식입니다. 이 버전은 텍스트 붙여넣기 등록만 제공합니다. PDF·이미지 분석 화면과 API 및 OCR 실행·설치 코드는 제거했습니다. 파일은 GPT 등 외부에서 분석하고, 이 사이트에는 완성된 텍스트를 붙여넣습니다.

## 실행

전체 소스 ZIP을 새 폴더에 풀고 기존 `.env`와 `uploads` 및 별도 `MODULE_DATA_DIR`의 데이터를 보존·연결한 다음 `npm ci`로 설치하고 서버를 재시작합니다. 이전 폴더에 덮어쓰면 삭제 대상 파일이 남으므로 새 폴더 사용을 권장합니다. 변경·삭제 목록은 루트의 정리 안내를 참고하세요. 새로운 npm 의존성은 없습니다.

Windows PowerShell에서 기존 실행 정책으로 npm.ps1이 차단되면 `npm.cmd start`를 사용합니다. 기존 PM2 등 별도 실행 관리가 있다면 해당 서비스를 재시작합니다.

## 사용

1. 28개 헤더와 모든 모델 행이 포함된 탭 구분 텍스트를 붙여넣습니다.
2. `모델별 검토표 만들기`를 누릅니다. 검토표 생성은 데이터를 저장하지 않습니다.
3. 모델별 수치·조건·파일명·출처 페이지를 확인합니다. 셀을 직접 수정할 수 있습니다.
4. 수정한 경우 `수정값 검사`를 누릅니다. 수정 후에는 기존 검토·동의 체크가 해제됩니다.
5. 등록할 정상 모델을 선택하고 원본 대조 및 적용 방식 동의를 직접 확인합니다.
6. `선택한 모델 등록`을 누릅니다. 열린 계산기를 새로고침하면 등록한 모델을 선택할 수 있습니다.

오류 모델은 선택할 수 없습니다. 정상 모델만 선택해서 등록할 수 있습니다. 서버는 선택한 자료를 다시 검사하며, 선택 자료에 오류·중복이 하나라도 있으면 그 요청에서는 아무 모델도 저장하지 않습니다. 최종 저장은 잠금과 원자적 파일 교체로 전체 선택 모델을 함께 기록합니다. 기존 모델을 덮어쓰지 않습니다.

제한은 한 번에 1~50개 모델, UTF-8 80KB입니다. 탭 대신 공백으로 정렬한 표, CSV, 열이 부족하거나 추가된 자료, 헤더 순서가 다른 자료는 거부합니다. BOM·CRLF와 전체를 감싼 text/tsv 코드 블록은 처리합니다. 숫자에는 단위나 천 단위 쉼표를 넣지 않습니다.

## 열과 원본 보존

`public/js/module-text-format.js`의 headers가 클라이언트와 서버의 공통 규격입니다.

```text
제조사	시리즈	모델명	STC출력_W	STC_Voc_V	STC_Vmp_V	STC_Isc_A	STC_Imp_A	STC효율_pct	Voc온도계수_pct_C	Isc온도계수_pct_C	Pmax온도계수_pct_C	최대시스템전압_V	최대직렬퓨즈_A	양면제품여부	양면적용방식	발전증가율_pct	양면출력_W	양면_Voc_V	양면_Vmp_V	양면_Isc_A	양면_Imp_A	후면일사율_pct	양면계수_pct	양면계수허용차_pct	양면시험조건	원본파일명	출처페이지
```

위 문서 표시의 `\t`는 탭을 뜻합니다. 실제로 복사할 자료는 `examples/*.tsv`를 사용하거나 GPT의 실제 탭 구분 출력을 사용합니다.

필수 숫자 16개를 검사하고 누락값·확인 필요·단위가 붙은 숫자는 자동으로 생성하거나 수정하지 않습니다. 출력과 Vmp×Imp 관계, 전압·전류 순서, 퓨즈 정격, 동일 제조사·모델명 중복도 검사합니다. 발전 증가율의 단순 검산과 원본 표기 사이에 차이가 있으면 경고하며, 반올림된 원본 수치를 변경하지 않습니다.

원본 파일명·출처 페이지·양면 시험 조건·출력 기준 양면계수·허용차·기준 후면 일사비·기재 발전 증가율은 `module.specification`에 보존합니다. 원래 28개 셀도 `catalog.json`의 `importCells`에 보존합니다. 미기재/해당없음 참고값은 메타데이터에서 null로 구분하고 원래 문자열은 importCells에 남깁니다.

이 경로는 첨부 파일을 업로드하지 않습니다. `sourceKind: text`, `pdfId: null`로 기록하며 원본 파일명은 사용자가 제공한 출처입니다. 원본 수치·시험 조건이 맞다는 사실을 GPT나 서버가 사용자 대신 확인하지 않습니다. 원본 대조 및 최종 동의는 관리자가 수행합니다.

## 계산 규칙

- `bnpi`: 기존 STC↔BNPI 선형 보정과 설계 모드를 유지합니다. 현재 기준은 전면 1000 / 후면 135W/m², 후면 일사비 13.5%입니다. 다른 기준은 자동 변환하지 않고 원본 확인을 요구합니다. 자료 재현 모드의 Voc는 기존처럼 STC를 사용합니다.
- `gain10`: 제조사 발전 증가율 10% 표의 출력·Voc·Vmp·Isc·Imp를 고정 기준으로 사용합니다. 제조사의 반올림을 보존하고 후면 일사율 보간을 하지 않습니다.
- `bstc`: 제조사 BSTC 표의 출력·Voc·Vmp·Isc·Imp를 고정 기준으로 사용합니다. 참고 발전 증가율·양면계수·후면 일사비를 다시 곱하지 않습니다.
- 고정 모드에서는 후면 일사율 입력을 비활성화하고 시험 조건을 표시합니다. 고정 모드의 Voc도 원본 양면 표에서 가져옵니다. 이전 gain10 자료 재현 모드의 STC Voc 대입과 달라지는 부분입니다.
- 모든 모드에서 기존 온도 보정, Voc 추가 여유와 전류 보정은 유지합니다. 설비 DC 용량 및 모듈 수량의 기준은 STC 출력입니다.
- Pmax 온도계수·모듈 효율은 현행 필수 등록 정보로 유지하되 기존 계산 엔진의 사용 범위를 확대하지 않습니다. Vmp 온도보정은 현재와 같이 Voc 계수, Imp 온도보정은 Isc 계수를 사용합니다.

## 예제와 검증

`examples/module-import-hansol.tsv`, `module-import-s-energy.tsv`, `module-import-canadian.tsv`는 대화에서 사용한 6개 BSTC·6개 BNPI·7개 gain10 모델의 형식 예입니다. 에스에너지 자료는 사용자가 제공한 추출 텍스트 기준이며 실제 등록 전 원본 PDF 대조가 필요합니다. 예제는 자동으로 등록되지 않습니다.

```sh
npm test
npm run test:ui
```

브라우저 검증은 환경 제공 Playwright와 `/usr/bin/chromium`을 사용합니다. 계산기 UI 검증에는 3000 포트가 비어 있어야 합니다. 테스트는 임시 관리자 계정과 임시 카탈로그를 사용하며 운영 데이터·메일을 사용하지 않습니다.
