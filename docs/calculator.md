# 계산기 선정 및 검증

A안은 허용 용량비와 전기적 제한을 충족하고 전체 모듈을 연결하는 후보에서
최소 대수 → 긴 직렬 활용 → 스트링 수 → 부하 균형 → 목표 비율 오차 순으로 선정합니다.
긴 직렬 활용의 점수는 각 모델의 최대 허용 직렬 수 대비 줄어든 모듈 수의 합입니다.
배분 내부의 균등화는 인버터 정격으로 가중한 DC/AC 비율 편차를 최소화합니다.
같은 MPPT에는 동일 직렬 수의 스트링만 연결합니다.

B안은 목표 AC/DC 오차가 가장 작은 조합입니다. 허용 편차 초과 및 미배분이
있을 수 있으므로 비교표와 선정 사유에서 경고합니다.

C안은 전량 연결·허용 편차 충족 후보에서 다음 점수를 최소화합니다.

```
0.4 × (목표 비율 상대오차 / 허용오차)
+ 0.3 × (대수 / 최소 가능 대수 − 1)
+ 0.3 × (스트링 수 / 후보의 최소 스트링 수 − 1)
```

허용오차가 0이면 점수 분모는 0.1을 사용하되, 후보 적격성은 실제 허용오차 0으로 판단합니다.
공통 조건은 STC 기준 AC/DC > 1이며, 인버터별 STC DC는 AC 정격 이내로 제한합니다.
이 DC 제한은 이번 설계의 보수적인 배분 정책이며 제조사의 최대 DC 입력 정격과는 다릅니다.

## 설정

- 기본 예비 설계: 최저 −20℃, 고온 Vmpp 계산용 온도 40℃,
  후면 13.5%(BNPI), Voc 추가 여유 5%, 단락전류 계수 1.25.
- 자료 재현 비교: 같은 온도·후면 조건, 저온 Voc는 STC 사양, 추가 여유 0%.
  단락전류 계수는 1.25를 유지하며 동작전압·전류는 BNPI 사양을 사용합니다.
- 두 설정 모두 Vmpp 온도계수는 선택 모듈의 Voc 계수를 임시 사용합니다.
- 설정 선택 시 위 입력값으로 초기화하고 즉시 자동 재계산합니다. 이후 직접 수정한 값은 계산 실행 시 그대로 사용하고 결과에 표시합니다.
- 주변 온도와 셀온도는 다릅니다. 자료 비교는 최종 설계 승인을 의미하지 않습니다.

## 대표 결과

500kW / HiS-T645NJ-ES / 775장 / AC/DC 목표 1.0 / 허용 편차 10%:

| 설정 | A안 | 스트링 | 연결 / 미배분 |
|---|---|---|---|
| 자료 재현 | 150kW×2 + 110kW×2 | 15직렬 47 + 14직렬 5 | 775 / 0 |
| 기본 예비 설계 | 150kW×2 + 110kW×2 | 14직렬 47 + 13직렬 9 | 775 / 0 |

자료 재현 A안은 인버터별 223·224·164·164장으로 배분합니다.
C안은 두 설정 모두 150kW×3 + 60kW×1, B안은 110kW×4 + 60kW×1이며 2장이 미배분됩니다.

## 탐색 범위

모델 조합을 대수 순으로 열거합니다. 계산량에 따라 후보는 최대 128개
(3,000kW 초과는 12개), 열거 방문 횟수는 20,000회로 제한합니다.
조합별 전역 배분 탐색의 전체 연산 예산을 소진하면 제한된 재배분 탐색을 사용합니다.
응답의 `selection.complete`, `selection.note`와 각 배분의 `optimization`으로
전체 탐색 여부를 구분하며, 제한된 경우 화면에도 표시합니다.

## 검증 실행

저장소 루트에서:

```sh
node --test --test-isolation=none test/calculator.test.js
node test/calculator-ui.cjs
```

브라우저 검증에는 Playwright와 Chromium이 필요합니다. 현재 클라우드 환경에
설치된 Playwright와 `/usr/bin/chromium`으로 확인했습니다. 다른 실행 파일은
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정할 수 있습니다.
브라우저 테스트는 서버의 Origin 정책에 맞춰 3000번 포트를 사용하고 종료 시 닫습니다.

## 입력 안내

설비용량 기준에서는 설비용량 → 모듈 제조사 → 인버터 AC 출력 순으로
파란 배경·테두리와 번호 배지를 표시합니다. 모듈 수량 기준에서는
모듈 제조사 → 모듈 수량을 강조합니다. 자동 계산 항목은 회색 입력과
자동 계산 배지로 구분하며, 모듈 수량 기준에서도 AC 출력 선택은 가능합니다.
기준을 전환하면 강조·입력 가능 여부·자동 계산 표시가 함께 전환됩니다.

## 배포 파일 및 캐시

고온 항목명은 `고온 Vmpp 계산용 온도 (℃)`입니다. `public/calculator.html`,
`public/js/calculator.js`, `server/calculator-engine.js`, `server.js`를 같은
프로젝트에 반영하고 Node.js 서버를 재시작합니다. 정확한 설치 경로와
캐시 확인 방법은 `APPLY_CALCULATOR_KO.md`를 참고하세요.
계산기 HTML과 JavaScript는 `Cache-Control: no-store`로 제공합니다.
클라이언트와 계산 서버 버전이 맞지 않으면 서버 재시작 안내를 표시합니다.

처음 계산기를 열면 A안을 기본 선택합니다. A안이 없는 조건은 B안을 표시하며, 사용자가 직접 고른 안은 이후 재계산에서도 가능한 경우 유지합니다.

설계 조건의 최초 선택은 **자료 재현 비교**입니다. 처음부터 Voc 여유 0%와 STC 저온 Voc 기준으로 계산합니다. A안 기본 선택은 유지합니다. 기본 예비 설계로 전환하면 Voc 여유 5%를 적용하고 자동 재계산합니다.
