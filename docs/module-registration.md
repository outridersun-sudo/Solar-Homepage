# 관리자 태양광 모듈 등록

관리자 로그인 후 `/reg-module.html`을 엽니다. 텍스트 붙여넣기 등록만 사용합니다.

1. 전용 추출 챗에 PDF·이미지를 제공하고 정해진 28개 열 TSV를 출력합니다.
2. 헤더와 모든 모델 행을 한 번에 복사합니다.
3. 등록 화면에 붙여넣고 `모델별 검토표 만들기`를 누릅니다.
4. 누락·오류·중복을 확인하고 필요한 값은 원본 자료 또는 직접 입력으로 보완합니다.
5. 수정값 검사를 실행하고 등록할 모델을 선택합니다.
6. 원본 대조 완료·양면 적용 방식 동의를 직접 확인한 뒤 등록합니다.

등록 화면은 `private/reg-module.html`에 있으며 인증 후에만 표시됩니다.
텍스트 검사·등록 API에는 기존 관리자 세션, Origin 및 CSRF 검증을 적용합니다.

## 계산 방식

- BNPI: 후면 일사율·설계 모드에 따라 기존 보정 계산을 수행합니다.
- gain10: 제조사의 발전 증가율 10% 표 사양을 고정 적용합니다.
- BSTC: 제조사 BSTC 원본 사양을 고정 적용합니다.
- 양면계수와 참고 발전 증가율을 원본 양면 전기 사양에 다시 곱하지 않습니다.
- 설비 DC 용량은 STC 기준이며 기존 온도·전압·전류 검토를 유지합니다.

자세한 입력 규격과 검증 방법은 [28개 열 텍스트 등록](module-text-import.md)을 참고하세요.

## 보존 데이터

카탈로그는 기본 `uploads/modules/catalog.json`, 또는 `MODULE_DATA_DIR`에 저장합니다.
기존 카탈로그는 형식을 변환하거나 삭제하지 않고 그대로 읽습니다.
과거 등록의 원본 PDF·이미지와 출처 정보가 남아 있어도 삭제하지 않습니다.

제품 자료실의 PDF 및 A/S·기술자료 업로드는 별도 기능이며 유지됩니다.
