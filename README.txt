천일테크윈 기업 홈페이지 샘플

1. 압축을 풉니다.
2. VS Code에서 폴더 전체를 Open Folder로 엽니다.
3. index.html을 더블클릭하거나 Live Server로 실행합니다.
4. 메뉴를 눌러 각 HTML 페이지 이동을 확인합니다.

구성:
- index.html            메인
- company.html          회사소개
- products.html         제품목록
- product-detail.html   제품상세
- downloads.html        기술자료실
- notices.html          공지사항
- css/style.css         공통 디자인
- js/main.js            공통 JS / 간단 검색


A/S 추가:
- as-service.html         A/S 안내 / 처리절차
- as-request.html         A/S 신청서 UI 샘플

현재 A/S 신청서는 화면 확인용이며 실제 서버 전송/저장은 하지 않습니다.
추후 Cloudflare Workers + D1 + R2 연동 시 실제 접수 기능으로 확장합니다.
