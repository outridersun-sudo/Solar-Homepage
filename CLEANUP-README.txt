Solar-Homepage v11 — 전체 소스 정리본 적용 안내

이 ZIP은 사용자가 제공한 README.zip을 기준으로 정리한 전체 소스입니다.
포함된 제품 이미지·카탈로그 PDF와 다른 홈페이지 소스는 보존했습니다.
업로드에서 제외된 public/company.html(회사소개)은 기존 저장소의 변경되지 않은 main 파일로 복원했습니다.

권장 적용 순서 (Windows):
1. 기존 서버를 중지하고 현재 프로젝트 전체를 백업합니다.
2. 이 전체 ZIP을 새로운 폴더에 풉니다. 단순 덮어쓰기로는 불필요한 파일이 삭제되지 않습니다.
3. 기존 .env와 uploads 폴더를 새 폴더로 보존·복사합니다.
   MODULE_DATA_DIR을 별도로 지정했다면 그 경로와 카탈로그·원본 데이터를 그대로 유지합니다.
   uploads에는 A/S 첨부·기술자료·모듈 카탈로그가 있을 수 있으므로 삭제하지 마세요.
4. 새 폴더에서 npm.cmd ci 를 실행합니다.
5. 기존 .env를 가져왔다면 보안 키를 그대로 사용합니다. 새 개발 환경이라면 node setup-security.js 로 생성할 수 있습니다.
6. 새 폴더에서 npm.cmd start 또는 기존 서비스 관리 방식으로 서버를 시작합니다.
7. 관리자에서 텍스트 붙여넣기·등록·계산기 선택을 확인한 뒤 새 폴더를 사용합니다.

보존·제외 사항:
- ZIP에는 .env, node_modules, .git, 실행 로그, 운영 uploads, OCR 모델이 없습니다.
- 과거 모듈 카탈로그와 PDF·이미지 원본은 운영 데이터이므로 제거하지 않습니다.
- 원본 파일명과 페이지는 텍스트 자료의 출처이며 이 버전은 모듈용 파일 업로드를 하지 않습니다.
- 제품 카탈로그 PDF, A/S 파일 첨부와 기술자료 업로드는 유지합니다.

정리 내용:
- 모듈 PDF/이미지 분석 화면, 클립보드 이미지 처리, 임시 업로드·분석 API 제거
- 해당 분석기 3개, OCR 설치 도우미와 전용 테스트 제거
- 등록 화면·목록 스크립트·스타일 및 문서를 텍스트 방식으로 정리
- 기존 잘못 배치된 SMTP 진단 파일은 public/scripts에서 scripts로 이동 (내용 동일)
- 삭제한 파일명은 REMOVED-FILES.txt 참고

Tesseract를 이 프로그램에서 더 이상 호출하지 않습니다. 다른 프로그램이 사용할 수 있으므로 시스템 설치 자체는 자동 제거하지 않습니다.
.env의 MODULE_TESSERACT_BIN, MODULE_OCR_DATA_DIR은 더 이상 이 프로젝트에서 사용하지 않으며 제거해도 됩니다. 다른 변수는 유지하세요.

검증: npm.cmd test
개발 환경 브라우저 검증: npm.cmd run test:ui (Playwright·Chromium 필요)

실제 DB 데이터·SMTP 발송은 별도 운영 설정을 사용하므로 이 정리 과정에서 변경하거나 발송하지 않았습니다.
